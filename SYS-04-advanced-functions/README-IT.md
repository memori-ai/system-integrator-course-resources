# SYS-04: Funzioni Avanzate

> Impara come creare e integrare funzioni avanzate per estendere le capacità del tuo agente AIsuru

## 🎯 Panoramica del Modulo

Questo modulo copre come creare funzioni avanzate che collegano i tuoi agenti AIsuru a REST API e servizi esterni. Impara a integrare dati in tempo reale, automatizzare la generazione di funzioni usando specifiche OpenAPI e costruire agenti AI potenti con capacità estese.

**Durata:** 2 ore

## 📚 Argomenti

| #   | Argomento                                | Descrizione                                                   |
| --- | ---------------------------------------- | ------------------------------------------------------------- |
| 1   | [Funzioni Avanzate](./manage_functions/) | Guida completa alla creazione e gestione di funzioni avanzate |

### Funzionalità della Demo Application

La demo **Funzioni Avanzate** include:

| Demo       | Tipo di Funzione                                | Descrizione                                           |
| ---------- | ----------------------------------------------- | ----------------------------------------------------- |
| **Demo 1** | Integrazione tramite API ad un servizio esterno | Collegare agenti a servizi REST usando API            |
| **Demo 2** | Import OpenAPI/Swagger                          | Auto-generare multiple funzioni da specifiche OpenAPI |

## 🎓 Obiettivi di Apprendimento

Al termine di questo modulo, sarai in grado di:

- ✅ Creare funzioni avanzate in AIsuru
- ✅ Configurare integrazioni webhook con REST API esterne
- ✅ Usare file OpenAPI/Swagger per auto-generare funzioni
- ✅ Collegare funzioni agli agenti e configurare il loro utilizzo
- ✅ Debuggare e verificare le chiamate alle funzioni nelle conversazioni
- ✅ Gestire parametri e risposte delle funzioni

## 🛠️ Prerequisiti

- Comprensione base di REST API e metodi HTTP
- Familiarità con i web component AIsuru (trattati in SYS-03)
- Accesso alla piattaforma AIsuru e credenziali agente
- Conoscenza base di JSON e parametri API
