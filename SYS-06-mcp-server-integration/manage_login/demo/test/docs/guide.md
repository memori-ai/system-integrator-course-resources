# User Guide

## Getting Started
Welcome to the Demo 3 workspace. This guide explains how the filesystem
MCP server works and what the agent can do with these files.

## Available Operations
The agent can perform the following actions on files in this workspace:

1. **List files** – browse the directory structure
2. **Read files** – display the full content of any file
3. **Write files** – overwrite an existing file with new content
4. **Create files** – add a brand-new file to the workspace

## Tips
- Ask the agent to modify this very file to see changes appear in the explorer.
- Try asking the agent to create a new file inside the `docs/` folder.
