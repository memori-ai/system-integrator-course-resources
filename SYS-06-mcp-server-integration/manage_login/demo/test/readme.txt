Welcome to the Demo 3 Filesystem Workspace
=============================================

This directory is shared between the demo Rails container and the MCP server container.
The AI agent connected to the MCP server can perform the following operations on files here:

- Read file contents
- List directory contents
- Create new files
- Modify existing files

Feel free to ask the agent to read this file, modify it, or create new files in this directory.
All changes are reflected immediately on the shared filesystem.
