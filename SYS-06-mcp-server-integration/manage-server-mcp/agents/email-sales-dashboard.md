# Demo 7: the project request email

> Send the block below as an email to the Outlook mailbox you connected in
> the run-through. The page offers it as a download so attendees can send it
> from their own client.

The figures are invented on purpose, and they are the whole proof of the demo.
A real-looking but guessable dataset (last quarter's public results, round
numbers like 400/300/200/100) would let the model produce a convincing
dashboard without ever opening the mailbox, and the room could not tell the
difference. 420 / 275 / 180 / 95 cannot be guessed: when those four numbers
appear on screen, the email was read.

Keep the requirements list concrete for the same reason. "Four KPI cards" and
"dark theme" are visible from the back of the room; "make it nice" is not.

If you edit this email, keep two properties: the numbers stay irregular, and
every requirement stays checkable by looking at the rendered page.

```
Oggetto: Richiesta progetto: Sales Dashboard Q1

Ciao,

ti giro la richiesta per il progettino di questa settimana. Serve una
dashboard delle vendite del primo trimestre, da mostrare in riunione
commerciale lunedi.

Dati da usare (fatturato Q1, in migliaia di euro):
- Nord: 420
- Centro: 275
- Sud: 180
- Estero: 95

Target di trimestre: 1.000 (migliaia di euro).

Top 5 prodotti per unita vendute:
1. Aurora CRM - 1.240 unita
2. Nimbus Backup - 980 unita
3. Vertex Analytics - 610 unita
4. Orbit Helpdesk - 455 unita
5. Lumen Reports - 310 unita

Requisiti:
- quattro KPI card in alto: fatturato totale, scostamento dal target,
  regione migliore, prodotto piu venduto
- una barra di avanzamento target vs actual
- un grafico a barre con il fatturato per regione
- una tabella con i top 5 prodotti
- tema scuro
- layout responsive, pagina singola HTML/JavaScript autoconsistente

Grazie!
Marta Bianchi - Direzione Commerciale
```
