# Workspace Directory

This directory is shared between the Rails application and the MCP filesystem server.

The AIsuru agent can:
- List files and directories
- Read file contents
- Write to existing files
- Create new files

Try asking the agent:
- "What files are in the workspace?"
- "Create a file called hello.txt with some content"
- "Read the contents of README.md"
- "Update hello.txt with new content"
